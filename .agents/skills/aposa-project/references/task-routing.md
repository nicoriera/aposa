# Task routing

Lire uniquement les documents nécessaires, en plus de `AGENTS.md` et `docs/README.md`.

| Type de tâche | Documents requis |
|---|---|
| Produit, édition, précommande | `PRODUCT.md`, `DOMAIN.md`, `DECISIONS.md` |
| Design, UX, contenu | précédents + `DESIGN.md`, `QA.md` |
| Frontend | `FRONTEND.md`, `DESIGN.md`, `API.md`, `TESTING.md` |
| Backend | `BACKEND.md`, `DOMAIN.md`, `API.md`, `DATA.md` |
| Commande ou paiement | backend + `SECURITY.md`, `QA.md`, `OPERATIONS.md` |
| Données ou migration | `DATA.md`, `SECURITY.md`, `OPERATIONS.md`, `TESTING.md` |
| QA ou tests | `QA.md`, `TESTING.md` et le domaine testé |
| Sécurité | `SECURITY.md`, `DATA.md`, `OPERATIONS.md` |
| Déploiement | `OPERATIONS.md`, `SECURITY.md`, `DECISIONS.md` |
| Agents, règles, documentation | `AGENT-WORKFLOW.md`, `README.md`, documents modifiés |

Tous les chemins de cette table sont relatifs à `docs/`.
